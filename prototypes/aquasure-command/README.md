# AquaSure Command

Bilingual Japanese/English aquaculture risk dashboard created for issue #90.

Live private preview: https://aquasure-risk-command.c2qrk2n8nk.chatgpt.site

## Features

- Kesennuma Bay, Owase Bay, and Shima Peninsula area switching
- Risk, sea temperature, chlorophyll-a, 7-day exposure, and model confidence metrics
- Selectable risk, temperature, and chlorophyll map layers
- Farm and monitoring-station statuses
- Alert rationale, recommended action, and acknowledgement audit logging
- Parametric coverage details, 72-hour outlook, and recent events
- Complete Japanese/English interface toggle

## Run locally

```sh
pnpm install
pnpm dev
```

This implementation is a self-contained prototype under `prototypes/aquasure-command` and does not replace the repository's existing frontend.
